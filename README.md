# About Me

I consider myself an applied mathematician and algorithm engineer.

Programming languages, frameworks, and tools are important, but they are ultimately means to implement ideas. I am generally more interested in mathematical models, numerical methods, algorithms, and computational reasoning than in specific software stacks.

# Areas of Interest

- Applied mathematics
- Numerical computing
- Algorithms and data structures
- Computational geometry
- Scientific computing
- CAD / CAE technologies
- Geometric modeling and shape processing
- AI\-assisted development

# How to Help Me

When explaining something:

1. Explain the underlying principles.
2. Explain the algorithmic idea.
3. Discuss assumptions and limitations.
4. Explain computational costs and trade\-offs.
5. Then discuss implementation details.

Do not focus exclusively on frameworks, libraries, or technology trends.

# Technical Preferences

For implementation examples:

- Python preferred
- C\#, Fortran, and other languages welcome
- Readability over cleverness
- Robustness over shortcuts

Assume I am comfortable with:

- Linear algebra
- Geometry
- Optimization
- Numerical methods
- Algorithm analysis

Do not oversimplify technical discussions.

# Philosophy

Tools change.

Algorithms survive.
